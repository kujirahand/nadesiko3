# なでしこの文法

この文章は、主にAIエージェントに向けて書いた、なでしこ3の文法です。なでしこのプログラムを作る際、この文法を参考にして作ってください。

## なでしこの基本

なでしこのプログラムは、日本語で可読性の高いものにします。ただし、自然言語ではなく、以下の文法に沿って動作します。

### 単語の区切り

トークンは、助詞や句読点、記号やスペースによって区切られます。文章を区切る助詞は、次のようなものです。

```json
["について","くらい","なのか","までを","までの","による","として","とは","から","まで","だけ","より","ほど","など","いて","えて","きて","けて","して","って","にて","みて","めて","ねて","では","には","んで","ずつ","は","を","に","へ","で","と","が","の","でなければ","なければ","ならば","なら","たら","れば","こと","である","です","します","でした","にゃん"]
```

### 命令文の基本的な文形について

なでしこのプログラムの構造は、以下のような形式になっています。

```md
引数＋助詞、引数＋助詞、 …関数名。
```

引数に計算式を記述することもできます。計算式は、`()`で囲むことで安全な引数として扱うことができます。

```md
(計算式)＋助詞、(計算式)＋助詞、 …関数名。
```

引数の中で、命令文を使うことができます。その際、命令文を丸カッコで囲むことで、正しい引数として扱うことができます。

```md
(引数+助詞、引数+助詞、関数名)＋助詞、引数＋助詞、 …関数名。
```

### コメント

- `#`から改行までをコメントと見なします。
- また、`/*`から`*/`までの範囲をコメントと見なします。

### 計算と演算子

利用できる計算と演算子は次の通り：

- `+` or `＋` --- 加算
- `-` or `－` --- 減算
- `*` or `×` --- 乗算
- `/` or `÷` --- 除算
- `%` or `％` --- 剰余
- `**` or `＾` --- べき乗

比較演算子は次の通り：

- `==` or `＝` --- 等しい
- `!=` or `≠` or `<>` --- 等しくない
- `>` or `＞` --- より大きい
- `<` or `＜` --- より小さい
- `>=` or `≧` --- 以上
- `<=` or `≦` --- 以下

論理演算子は次の通り：

- `&&` or `かつ` --- 論理積
- `||` or `または` --- 論理和

ビット演算子は次の通り：

- `<<` --- 左ビットシフト
- `>>` --- 右ビットシフト
- `>>>` --- 右ビットシフト（左ビット0埋め）

### 値表現について

- 整数は、10進数、16進数(0xXX0、8進数(0oXX)、2進数(0bXXXX)で表現できます。
- 真偽値は、`真` と `偽` で表現できます。それぞれ、なでしこ3では、JavaScriptの`true`と`false`に変換されて実行されます。
- 文字列は、`「...」`(展開あり) or `『...』`(展開なし)、または、`"..."`(展開あり) or `'...'`(展開なし)で囲むことで表現できます。
  - 展開あり文字列の中では、`「{改行}」` や `「{タブ}」` などのエスケープシーケンスを使うことができます。また、`「{変数名}」` のように書くことで、変数の値を展開することができます。
  - `改行`や`タブ`、`CR`、`LF`などが指定できますが、これは、変数として定義されています。
- JSONは、プログラム中に、そのまま、辞書型・配列型として表現できます。JSONの中では、`{"キー": 値}`または、`[値1, 値2, ...]`のように書くことができます。
- 範囲を、`A…B` or `A...B` or `AからBの範囲`のように書くことで、AからBまでの範囲を表現できます。

### 変数について

- 「リンゴ値段」と「リンゴ個数」という変数を定義して、プログラムの中で使えます。
- ただし、変数名に助詞を含めることはできません。変数名は、助詞を除いた文字列で定義してください。
- プログラムを分かりやすくするために助詞を使いたい時は、`《バナナの値段》`のように、変数名を括弧で囲むことで、助詞を含めた変数名として扱うことができます。
- 配列変数は、`変数[インデックス]`のように、角括弧で囲むことで表現できます。インデックスは、0から始まる整数で指定します。
  - `変数@要素番号`のように記述することもできます。
  - 配列変数の要素数は、`変数の要素数`のように記述することで取得できます。
  - `Aの3…5を参照`のように記述して、配列の一部を参照することもできます。
- 辞書型配列は、`変数[キー]`のように、角括弧で囲むことで表現できます。キーは、文字列で指定します。
  - `変数@キー`のように記述することもできます。

## 制御構文

### 代入文

以下のように代入文を記述できます。以下の4行は同じ意味です。

```nako3
値段は3000  # 推奨
値段 = 3000
値段＝3000
値段に3000を代入
```

複数代入文は下記のように記述します。

```nako3
変数[A,B,C] = [1,2,3]
```

### 定数の定義

定数は次のように記述できます。

```nako3
定数の値段は320  # 推奨
値段を320に定める
定数[値段1, 値段2] = [320, 640]
```

### ifに相当する条件分岐

次の書式で記述します。Python風にインデントして構文を書く事ができます。

```nako3
もし、(比較式)ならば:
    (処理)
違えば:
    (処理)
```

単文の場合は、次のように書くこともできます。

```nako3
もし、(比較式)ならば、(処理)
```

### switchに相当する条件分岐

多分岐は、次のように書くことができます。

```nako3
値で条件分岐：
　　1ならば：
　　　　「1」と表示。
　　2ならば：
　　　　「2」と表示。
　　違えば：
　　　　「その他」と表示。
```

### 単純なループ

指定回数の繰り返し

```nako3
N回:
　　＃ここにN回繰り返したいプログラム
```

条件文を指定した繰り返し

```nako3
(条件)の間:
　　＃ここに条件が真の間繰り返したいプログラム
```

### 範囲指定したループ

指定範囲を指定した繰り返し：

```nako3
(変数名)で開始値から終了値まで繰り返す：
    # ここに繰り返したいプログラム
```

範囲を指定した繰り返し

```nako3
(変数名)で開始値…終了値まで繰り返す：
    # ここに繰り返したいプログラム
```

なお、変数名は省略できます。省略した場合、`それ`という変数名に回数が代入されます。

### 反復ループ(forEachに相当)

```nako3
(変数名)で(値)を反復：
    # ここに繰り返したいプログラム
```

変数名は省略できます。省略した場合、`対象`という変数名に値が代入されます。

### エラー制御

```nako3
エラー監視:
    # ここに監視対象のプログラム
エラーならば:
    # ここにエラー時の処理
```

例外を発生させる場合は、次のように記述します。

```nako3
「エラー内容」のエラー発生
```

## 関数の定義

関数の定義は以下のように記述します。

```nako3
関数 (引数1, 引数2, ...)関数名とは:
    # ここに関数の処理
```

なお、引数の部分は、それぞれ`変数名+助詞`で記述します。
例えば、足し算をするだけの関数`加算処理`を定義する場合は、次のように記述します。

```nako3
関数 (AとBの)加算処理とは:
    A+Bを戻す。
```

関数のエイリアスが`●`です。

```nako3
●(AとBの)加算処理とは:
    A+Bを戻す。
```

### 関数の呼び出し

関数の呼び出しは、次のように記述します。

```nako3
(引数1+助詞、引数2+助詞、...)関数名。
```

### ローカル変数

以下のように、「変数のA=50」のように書いて、関数内でローカル変数を定義することができます。

```nako3
●ローカルテスト処理とは：
  変数のA=50
```

### 戻り値について

関数の戻り値は、`戻す`や`戻る`という命令で返すことができます。`戻る`がない場合、最後の関数呼び出しが戻り値となります。

```nako3
関数 (AとBの)加算処理とは:
    AにBを足すこと

3と5の加算処理を表示 # →8
```

または、連文を使うこともできます。

```nako3
関数 (AとBの)加算処理とは:
    AにBを足して戻す

3と5の加算処理を表示 # →8
```

### 連文

連文`AしてB`を使うと、Aの結果をBの最初の引数として渡すことができます。連文は、関数の戻り値を次の関数の引数として渡す場合に便利です。

```nako3
3と5を足して表示  # 3と5を足すの結果が表示の最初の引数になる
```

## 取り込む

外部のなでしこのプログラムや、JavaScriptで書かれたなでしこ用プラグインを取り込んでモジュールとして利用できます。

```nako3
！「ファイル名」を取り込む。
```

全ての変数は「ファイル名__変数名」のルールで管理されます。ファイル「A.nako3」とファイル「B.nako3」で同名の変数「価格」を宣言した場合、それぞれ「A__価格」と「B__価格」いう名前で変数にアクセスが可能です。

## なでしで使える関数について

なでしこで使える命令の一覧が、`batch/command.txt`にあります。

なお、、システム命令が、`core/src/plugin_system.mts`に定義されています。

ブラウザ上で使える命令が、`src/plugin_browser.mts`に定義されています。
