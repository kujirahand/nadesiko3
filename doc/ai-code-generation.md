# 生成AIになでしこ3のプログラムを作ってもらう

生成AIに目的を伝えると、なでしこ3のプログラムを作成してもらえます。ただし、生成AIがなでしこ3の命令名や助詞を推測すると、存在しない命令や正しくない文法を使うことがあります。

このチュートリアルでは、リポジトリ内の文法資料と命令一覧をAIに参照させ、生成したプログラムを実行して確かめる方法を紹介します。

## 準備

GitHubからなでしこ3を取得し、依存パッケージをインストールします。

```sh
git clone https://github.com/kujirahand/nadesiko3.git
cd nadesiko3
npm install
```

CodexやClaude Codeなど、リポジトリ内のファイルを読み書きしてコマンドを実行できるAIエージェントで、このディレクトリを開きます。

## 最初のプログラムを作る

まず、AIエージェントに次のように依頼します。

```text
1から10までの合計を表示する、なでしこ3のプログラムを作ってください。
Node.js版のcnako3で動くようにして、sample.nako3へ保存してください。
作成後に実行し、正しく動くことを確認してください。
```

AIは、このリポジトリの`AGENTS.md`に記載された手順に従い、文法と命令を確認してからコードを生成します。生成されるプログラムは、例えば次のようになります。

<!-- ai-code-generation-example:start -->
```nako3
答=0
Iで1から10まで繰り返す:
  答=答+I
「合計は{答}です」と表示
```
<!-- ai-code-generation-example:end -->

次のコマンドで実行できます。

```sh
node src/cnako3.mjs sample.nako3
```

実行結果は次の通りです。

```text
合計は55です
```

## AIが参照する資料

AIには、次の2つのファイルを正本として使わせます。

- `doc/syntax-nako3.md`: 変数、条件分岐、繰り返し、関数定義などの文法
- `doc/command_list.json`: 命令名、引数と助詞、説明、実行環境などの命令情報

`doc/command_list.json`の各項目で、特に重要なフィールドは次の通りです。

- `name`: 命令名
- `args`: 引数と助詞。例えば`Sを/Sと`なら、「を」または「と」で引数を渡せる
- `target`: 対応する実行環境。`cnako`はNode.js版、`wnako`はブラウザ版
- `group`: `基本プラグイン`または`拡張プラグイン`
- `description`: 命令の説明
- `url`: 命令を定義しているソースコード

命令一覧は大きなファイルです。AIにはファイル全体を回答へ貼り付けさせず、目的や命令名に合わせて必要な項目だけを検索させてください。

## より正確に作ってもらうためのプロンプト

実用的なプログラムでは、目的だけでなく、実行環境、入力、出力、制約、確認方法も伝えます。

```text
なでしこ3で、CSVファイルを読み込み、2列目の数値の合計を表示する
プログラムを作ってください。

条件:
- Node.js版のcnako3で動かす
- doc/syntax-nako3.mdの文法に従う
- 使用する命令はdoc/command_list.jsonで確認する
- targetにcnakoを含む命令だけを使う
- 命令のargsに記載された助詞を守る
- 拡張プラグインが必要なら、コードを作る前に説明する
- sample.nako3へ保存する
- node src/cnako3.mjs sample.nako3で実行確認する
- エラーになった場合は、原因を調べて修正し、再実行する
```

ブラウザ版のプログラムが必要な場合は、`Node.js版のcnako3`を`ブラウザ版のwnako3`に置き換えます。その場合、`target`に`wnako`を含む命令を使うように指定してください。

## 既存のプログラムを修正してもらう

エラーが発生するプログラムを直してもらう場合は、対象ファイルと実行方法を伝えます。

```text
sample.nako3を実行するとエラーになります。
doc/syntax-nako3.mdとdoc/command_list.jsonを確認して修正してください。
修正後、node src/cnako3.mjs sample.nako3を実行し、結果を確認してください。
```

実行環境を持たないチャット型AIを使う場合は、エラーメッセージを省略せずに貼り付けて、修正を依頼してください。

## よくある失敗

### 存在しない命令を使う

AIが、意味から命令名を推測してしまうことがあります。`doc/command_list.json`を検索し、実在する命令だけを使うように依頼してください。

### 助詞が合っていない

なでしこ3では、命令へ引数を渡す助詞が決まっています。命令一覧の`args`を確認してください。

### 実行環境が違う

DOM操作などはブラウザ専用、ファイル操作などはNode.js専用の場合があります。命令一覧の`target`に、目的の実行環境が含まれるか確認してください。

### 拡張プラグインの命令をそのまま使う

`group`が`拡張プラグイン`の命令は、別パッケージのインストールや取り込みが必要になることがあります。AIに導入方法も確認させてください。

### 命令名を変数名に使う

命令名と同じ名前を変数へ使うと、代入時に文法エラーになることがあります。エラーが出た場合は、命令一覧を検索して変数名と命令名が衝突していないか確認してください。

## 最後に確認すること

AIがプログラムを生成したら、次を確認します。

1. 希望した`cnako`または`wnako`向けになっているか。
2. 使用した命令が`doc/command_list.json`に存在するか。
3. 命令の助詞が`args`と一致しているか。
4. 必要な入力例と期待する出力が示されているか。
5. 実際に実行し、エラーなく期待した結果が得られるか。

生成AIの回答をそのまま完成品とせず、「資料を確認する」「実行する」「エラーを直す」という手順を繰り返すと、正確ななでしこ3プログラムを作りやすくなります。
