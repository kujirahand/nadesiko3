# ゴール

Node.js(JavaScript)で書かれたサーバー`index.mjs`を、完全に、なでしこ3のプログラムとして書き直すことを目標とします。

作成したプログラムは、`index.nako3`として、なでしこ3のプログラムとして実行できるようにします。

## コンテキスト

なでしこの文法は、`doc/syntax-nako3.md`にまとめられています。

## デバッグについて

```sh
# プログラム index.nako3を実行する
cnako3 index.nako3
```

プログラムの構造を理解するには、次のコマンドで、プログラムの構造(文法構造ツリー)を表示することができます。

```sh
# ASTを表示する
cnako3 --ast index.nako3
```
