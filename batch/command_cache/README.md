# command_cache

`batch/pickup_command.nako3` が拡張プラグインの命令を抽出した結果を、プラグイン（リポジトリ）ごとにキャッシュしたものです。

拡張プラグインは、nadesiko3 本体の親ディレクトリに兄弟としてクローンされた関連リポジトリ（nadesiko3-music など）から抽出します。クローンがない環境では、このキャッシュを使って命令一覧（`doc/command_list.json` など）を補完します。クローンがある環境で生成すると、抽出結果でキャッシュが自動的に更新されます。

拡張プラグインの命令を追加・変更した場合は、関連リポジトリをクローンした環境で `npm run build:command` を実行し、更新されたキャッシュも一緒にコミットしてください。

## 注意事項

- 生成の前に、関連リポジトリを最新の状態に更新してください（古いクローンで生成すると、キャッシュが古い内容に戻ってしまいます）。
- キャッシュのファイル名はリポジトリ名（例: `nadesiko3-music.txt`）です。1つのリポジトリから抽出するプラグインファイルは1つだけという前提です。
- `batch/pickup_command.nako3` の拡張プラグイン一覧からプラグインを外した場合は、対応するキャッシュファイルも手で削除してください。
